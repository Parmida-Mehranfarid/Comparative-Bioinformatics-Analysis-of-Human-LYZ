# Tools & Databases Used

| Tool / Database | URL | Used for |
|---|---|---|
| NCBI Gene / Nucleotide / Protein | https://www.ncbi.nlm.nih.gov/ | Retrieving mRNA and protein sequences (Gene ID 4069) |
| BLAST (blastn, blastp) | https://blast.ncbi.nlm.nih.gov/Blast.cgi | Finding homologous sequences |
| Clustal Omega | https://www.ebi.ac.uk/jdispatcher/msa/clustalo | Multiple sequence alignment |
| MEGA | https://www.megasoftware.net/ | Phylogenetic tree construction (Neighbor-Joining, Poisson correction), genetic distance matrix |
| PSIPRED | https://bioinf.cs.ucl.ac.uk/psipred/ | Secondary structure prediction |
| SWISS-MODEL | https://swissmodel.expasy.org/ | Tertiary (3D) structure homology modeling |
| ExPASy ProtParam | https://web.expasy.org/protparam/ | Physicochemical property calculation |
| NCBI Primer-BLAST | https://www.ncbi.nlm.nih.gov/tools/primer-blast/ | PCR/qPCR primer design and specificity checking |
